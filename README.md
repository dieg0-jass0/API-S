# API-S

## Descripción del proyecto

Práctica de la materia Interacción con Servicios Digitales.

Es una SPA (Single Page Application) que consume APIs y utiliza WebSockets para Chat en tiempo real. El Dashboard se compone de cuatro secciones:

- Correo
- Comercio Electrónico
- Multimedia
- Chat con WebSockets
